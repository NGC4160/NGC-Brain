# Motors — known-faulted

File only motor captures where a fault was **proven by test** (not “motor is the usual suspect”). Each file must record year/make/model, motor type, the proven failure mode, test points, and meter/scope settings, plus which known-good criteria failed: **voltage, timing, shape, stability, frequency, load response**, and how the motor signal disagreed with throttle, solenoid, or controller output. Prefer a side-by-side pointer to a matching known-good when one exists. No customer PII, job numbers, or invented waveforms.
