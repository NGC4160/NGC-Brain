## 7-Point Golf Cart Inspection Report

**PDF:** [NGC_Golf_Cart_Inspection_Report.pdf](NGC_Golf_Cart_Inspection_Report.pdf)

**Command Center:** Documents → Operations → 7-Point Golf Cart Inspection Report

### What it is

One-page printable form for complimentary battery testing + the free **7-point safety inspection**. Used at campground / free inspection events and as a customer-facing record tied to promo code **INSPECT10** (10% off any service when presented at booking).

### How to use

1. Print blanks before the event (or for shop walk-ins who want the complimentary check).
2. Fill customer / cart header, static pack voltage, and per-battery Δ / mOhm.
3. Mark Pass / Fail / N/A on all seven safety points.
4. Write recommendations; inspector signs.
5. Give the sheet to the customer — Jesse honors **INSPECT10** when they book.
