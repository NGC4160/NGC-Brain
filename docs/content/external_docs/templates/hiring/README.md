## Phone interview scorecard

**PDF (use this on the call):** [NGC_Technician_Phone_Interview_Scorecard.pdf](NGC_Technician_Phone_Interview_Scorecard.pdf)

**Regenerate:** `python3 generate_phone_screen_pdf.py`

### How to use

1. Print or open the PDF before the Indeed-cleared candidate call (15–20 min).
2. Skip logistics — already handled on the Indeed application.
3. Score sections **A–G** (1–4). **E Safety is a gate** (must be ≥ 3).
4. Golf cart / lithium (**H**) is bonus only — not required.
5. Advance → schedule the 3–4 hour shop evaluation (written / hands-on / troubleshooting).
