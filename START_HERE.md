# NGC Business Brain — Start Here

Open this project in **Cursor** and chat with the AI to run and improve Neighborhood Golf Carts daily.

**NGC Command Center:** [ngc4160.github.io/NGC-Brain/command-center](https://ngc4160.github.io/NGC-Brain/command-center/) — owners-only hub for live ops, systems, and everything being built. Setup: [`docs/COMMAND_CENTER.md`](docs/COMMAND_CENTER.md)

## Quick start (60 seconds)

1. Open **Cursor** → open this folder as your workspace
2. Start a new chat (`Cmd+L` / `Ctrl+L`)
3. Paste a prompt from [`prompts/`](prompts/) or type:

```
Morning briefing — what's on my plate today as service manager?
Use knowledge/ and tell me what you need from me if anything is missing.
```

The AI reads `knowledge/` automatically via `.cursor/rules/`.

## One source of truth

**`knowledge/` is the only place to edit shop rules.** Numbered folders (`01_company` … `11_future_lines`) stay as they are — do not rebuild that map.

| Path | Role | Edit here? |
|------|------|------------|
| `knowledge/` | Canonical shop rules | **Yes** |
| `external_docs/templates/` | Canonical hiring / ops / counseling forms | **Yes** |
| `docs/content/` | Publish copy for Command Center viewer | **No** — generated by `scripts/build_command_center.py` (morning-sync + Pages) |
| `docs/documents/` | Command Center Documents hub copies | **No** — generated from `scripts/documents_catalog.py` + templates |
| `docs/live/` and `knowledge/.generated/` | Generated ops snapshots (counts, invoice #) | **No** — not policy |
| `docs/training/` | 10-week diagnostic training pack | Yes, but **not** shop policy and **not** Jesse’s tech binder |

Morning sync is **HCP + QBO**, plus an optional **Drive catalog** (`knowledge/.generated/drive_catalog.md`) when `GOOGLE_DRIVE_SERVICE_ACCOUNT_JSON` is set. Live file **content** is the Google Drive connector (NGC985). Staff SOPs stay in Drive. `external_docs/My Drive/` is **not** a live sync.

Personal / non-shop projects (Blake’s birdhouses) belong in [NGC4160/PersonalProjects](https://github.com/NGC4160/PersonalProjects), not this repo.

## What to tell the AI each session

Paste or summarize:

- Jobs in the shop today (cart make/model, issue, tech assigned)
- Any numbers you want analyzed (export fresh QBO/HCP first)
- Decisions you made ("we're setting paid pickup at $99 for all Southshore")
- Questions for staff (Jesse, Hayden Silva, techs) or Jessica at Griffin & Furman (books)

**Do not paste** customer phone numbers or addresses unless necessary — look those up in HCP.

## Keep the brain current

**Chief** (Ryan's Grok Bot COS) and shop bots must operate from this brain and write durable facts back here the **same day** Ryan corrects them — roster, policy, and workflow changes belong in `knowledge/`, not only in chat. Ryan talks **ONLY** to Chief; Chief routes every task and brings results back in Chief’s thread ([roles.md](knowledge/05_team/roles.md#chief-routing-standing)).

When something changes, either:

1. **Tell the AI in chat** — it can update `knowledge/` files for you, or
2. **Re-export** to `external_docs/exports/` and say **"sync exports"** (runs `scripts/sync/run_ingest.sh`)

Do **not** edit `docs/content/` or `docs/documents/` copies of the same markdown. After a knowledge or template change, `python3 scripts/build_command_center.py` (or morning-sync / Pages) republishes them.

Track decisions in [`knowledge/09_daily_ops/decision_log.md`](knowledge/09_daily_ops/decision_log.md).
