## What runs automatically today

| Trigger | Action |
|---------|--------|
| **Daily 7:30 AM CST** | GitHub Action `morning-sync.yml` — HCP + QBO + optional Drive catalog → Command Center |
| **Cursor session start** | Hook runs `ingest_exports.py` → updates `knowledge/.generated/sync_manifest.json` |
| **After export file edit** | Hook re-runs ingest |
| **You say `/sync`** or "sync exports" | Skill runs ingest + offers knowledge diff |

Run manually anytime:

```bash
./scripts/sync/run_morning_sync.sh   # HCP + QBO + Drive catalog + Command Center
./scripts/sync/run_drive_sync.sh     # Drive catalog only (skips if no secret)
./scripts/sync/run_ingest.sh         # exports only
```

## Connectors to set up (priority order)

### 1. QuickBooks Online MCP — **do this first**

**Why:** Eliminates monthly xlsx exports; live P&L, balance sheet, COA, aged AR.

**Steps:** See [integration_playbook.md](integration_playbook.md#quickbooks-online-mcp)

**Template:** [`../../.cursor/mcp.json.example`](../../.cursor/mcp.json.example)

### 2. Google Drive — catalog + connector (not a My Drive git clone)

- **Live content:** Google Drive connector (NGC985).
- **Brain catalog:** `knowledge/.generated/drive_catalog.md` — generated by `scripts/sync/run_drive_sync.py`.
- **Actions:** optional secret `GOOGLE_DRIVE_SERVICE_ACCOUNT_JSON`. Missing = skip Drive; do not fail HCP/QBO.
- **`external_docs/My Drive/`** is not a live sync.

Do not download File_000 or files over 10MB. Catalog only.

### 3. Housecall Pro
