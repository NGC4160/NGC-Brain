# Throttles — known-good

File only confirmed-good throttle / ITS / inductive / hall / pot captures after the cart was proven healthy. Each file must record year/make/model, throttle type, test points (supply, signal, ground), pedal position for each trace, and meter/scope settings, plus the known-good criteria used: **voltage, timing, shape, stability, frequency, load response**, and how the signal relates to pedal travel, HPD/sequencing, and controller throttle input. Do not store a trace here until those criteria were met. No customer PII, job numbers, or invented waveforms.
