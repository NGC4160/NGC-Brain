# Known-good captures

Store **confirmed-healthy** traces only — taken on a cart that passed the same tests you will use on a complaint cart. Subfolders: [motors](motors/README.md), [solenoids](solenoids/README.md), [controller-io](controller-io/README.md), [throttles](throttles/README.md), [control-circuits](control-circuits/README.md).

Every capture must name year/make/model, test points, meter/scope settings, and the known-good criteria: **voltage, timing, shape, stability, frequency, load response, and signal relationships**. No customer PII, no HCP job numbers, no invented traces. This folder is empty until a tech files a real known-good.
